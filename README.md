## Elegoo Conqueror AI Driver

This project aims to provide a way to have your Elegoo Conqueror robot be controlled by an AI model. This is a huge WIP and will move quite slowly as I am not familiar with embedded rust and I have another project that I value more that I am working on right now.

In theory the AI model would be fed the video feed of the robot's camera through the robot's wifi connection and the model would then send back instructions.
